Xattot — Özbekça (Xattot) input method va Özbekça Tugmali (Xattot) layout,
yangi lotin alifbosi (OʻRQ-1184)

ÖRNATIŞ (ilova bilan — tavsiya)
1. "Xattot" ni yonidagi "Applications" papkasiga sudrab taşlang.
   DMG içidan oçib yuborsangiz ham bölaveradi: ilova özini Applications'ga
   köçiriş taklif qiladi.
2. Applications'dan oçing. Ilova Apple'da röyxatdan ötmagan, şuning uçun
   macOS birinçi marta oçmaydi. System Settings > Privacy & Security ga kirib,
   pastdagi "Open Anyway" ni bosing va parolni kiriting. Bu bir marta qilinadi.
3. Menyu satrida Ö belgisi paydo böladi. Uni bosib "Yoqiş" ni tanlang
   (yoki ⌃⌥O ni bosing). macOS ruxsat söraydi — "Allow" ni bosing.
   Ogohlantiriş matni barça uçinçi tomon klaviaturalari uçun bir xil.
   Input method siz yozayotgan sözni köradi, lekin internetga ulanmaydi va
   hech narsani hech qayerga yubormaydi.

Ilova menyusida: Özbekça (Xattot) yoki Tugmali'ni tanlaş, shortcutni özgartiriş
va kompyuter yonganda avtomatik işga tuşiş.
Tizimning öz til belgisi (A, Ö) ham menyu satrida tursa, uni öçirsa böladi:
System Settings > Keyboard > Input Sources > "Show Input menu in menu bar".

QANDAY IŞLAYDI
  ch  -> ç      Ch, CH -> Ç
  sh  -> ş      Sh, SH -> Ş
  o'  -> ö      O' -> Ö     (o` ham böladi)
  g'  -> ğ      G' -> Ğ     (g` ham böladi)
  san'at -> sanʼat          (söz içidagi ' tutuq ʼ böladi,
                             söz boşi va oxiridagi qöştirnoq özgarmaydi)

Input method butun sözni köradi, şuning uçun hech bir harf kutib qolmaydi:
- Enter çat dasturlarida xabarni birinçi bosişdayoq yuboradi, Spotlight'da
  "arc" + Enter Arc'ni oçadi.
- Chrome, Slack, VS Code kabi dasturlarda bir harfli yorliqlar işlaydi.
- Xato harfni öçirsangiz ham "s" keyingi "h" bilan birikadi.
- Parol maydonlarida hech bir harf almaşmaydi.

OPTION BILAN
  Option+C / S / G / O   ->  ç ş ğ ö   (Shift bilan: Ç Ş Ğ Ö)
  Option+H               ->  oddiy h, birikmaga qöşilmaydi:
                             p u s Option+H  ->  push
  Option+'               ->  tutuq belgisi ʼ istalgan joyda

INGLIZÇA SÖZLAR
Sözda "w" yoki "h" siz "c" bölsa, u özbekça emas: sözning qolgan qismi
özgarmaydi. wish, watch, cash, code öz holiça yoziladi.
Boşqa inglizça sözlar ham imlosini saqlaydi: change, push, shop, Chrome, don't.
Söz tugaganda (böşliq, tiniş belgisi, Enter) input method uni tekşiradi va
inglizça bölsa asl yozilişini qaytaradi. boş, tuş, çin, çap kabi özbekça sözlar
özbekça qoladi. Markdown'dagi `kod` içida harflar almaşmaydi.
Qolgan barça tugmalar ABC bilan bir xil, Cmd/Ctrl yorliqlari ham.

TUGMALI VARIANT
Ikkinçi variant — "Özbekça Tugmali (Xattot)" layout: har bir harf uçun alohida
tugma, birikma yöq. U dastur emas, faqat harflar jadvali.
  [  ->  ö   Shift+[  ->  Ö
  ]  ->  ğ   Shift+]  ->  Ğ
  ;  ->  ş   Shift+;  ->  Ş
  '  ->  ç   Shift+'  ->  Ç
  `  ->  ʼ   (tutuq), oddiy ` esa Option+` da
Tugmasini harfga bergan belgi Option bilan öz tugmasida qoladi: Option+[ -> [,
Shift+Option+[ -> {, Option+; -> ;, Option+' -> ' va hokazo.
Option+9 -> “   Option+0 -> ”   Shift+Option+9 -> ‘   Shift+Option+0 -> ’
« » ABC dagidek Option+\ va Shift+Option+\ da.
Qolgan barça tugmalar ABC bilan bir xil: Cmd/Ctrl yorliqlari ham, ABC'dagi
Option bilan yoziladigan urğu belgilari (é, ü kabi) ham özgarmaydi.
Ilova bir vaqtda faqat bittasini yoqilgan holda saqlaydi. Har biri birinçi
marta yoqilganda macOS ruxsat söraydi. Tugmali yoqiq bölsa, parol maydonida
ilova vaqtinça ABC ga ötadi va maydondan çiqqanda qaytaradi.

ÖRNATIŞ (faqat Tugmali layout, ilovasiz)
GitHub release'dagi Xattot-layout.zip ni oçib, Xattot.bundle ni
~/Library/Keyboard Layouts papkasiga qöying (Finder: Go > Go to Folder).
Keyin System Settings > Keyboard > Input Sources > Edit > + > "Özbekça Tugmali"
ni qöşing. Röyxatda körinmasa, bir marta Log Out qilib qayta kiring.
Almaştiriş: Ctrl+Space yoki Globe tugmasi. Ilovasiz parolni ABC da yozing.
