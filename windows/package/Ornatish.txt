Xattot — Özbekça Tugmali (Xattot) klaviaturasi Windows uçun,
yangi lotin alifbosi (OʻRQ-1184)

ÖRNATIŞ
1. Zip arxivni oçing va içidagi hamma narsani bitta papkaga çiqaring
   (arxiv içidan turib işga tuşirmang).
2. install.cmd ni ikki marta bosing. Windows "Unknown publisher" yoki
   SmartScreen ogohlantirişini körsatsa: "More info" > "Run anyway".
   Fayllar imzolanmagan, şuning uçun ogohlantiriş çiqadi.
3. Administrator ruxsati söraladi — "Yes" ni bosing. Layout
   C:\Windows\System32 ga köçiriladi va Özbekça tiliga qöşiladi.
4. Win+Space bilan Özbekça Tugmali (Xattot) ni tanlang. Röyxatda
   körinmasa, bir marta Sign out qilib qayta kiring.

Talab: Windows 10 yoki 11, 64-bit (Intel/AMD yoki ARM).

QANDAY IŞLAYDI
  [  ->  ö   Shift+[  ->  Ö
  ]  ->  ğ   Shift+]  ->  Ğ
  ;  ->  ş   Shift+;  ->  Ş
  '  ->  ç   Shift+'  ->  Ç
  `  ->  ʼ   (tutuq), Shift+` -> ~
Caps Lock yangi harflarni ham katta qiladi.
Tugmasini harfga bergan belgi AltGr (öng Alt) bilan öz tugmasida qoladi:
AltGr+[ -> [, Shift+AltGr+[ -> {, AltGr+; -> ;, AltGr+' -> ', AltGr+` -> `.
AltGr+9 -> “   AltGr+0 -> ”   Shift+AltGr+9 -> ‘   Shift+AltGr+0 -> ’
AltGr+\ -> «   Shift+AltGr+\ -> »
Öng Alt yöq klaviaturada AltGr örnini Ctrl+Alt bosadi.
Qolgan barça tugmalar US klaviaturasi bilan bir xil, Ctrl yorliqlari ham.

Layoutda kod yöq: kbduzxt.dll faqat harflar jadvali, hech narsa
import qilmaydi, hech narsani öqimaydi va hech qayerga yubormaydi.

ÖÇIRIŞ
uninstall.cmd ni ikki marta bosing. Layout Özbekça tilidan va tizimdan olib
taşlanadi; tilda boşqa klaviatura qolmasa, til ham röyxatdan çiqadi.
Windows layoutni işlatib turgan bölsa, fayl keyingi qayta yuklaşda öçadi.
